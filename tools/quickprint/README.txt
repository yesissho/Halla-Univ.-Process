탐색기 선택 파일 목록 추가 기능

설치 후 Quick Print에서 프린터를 선택해 둡니다.
창을 최소화하고 파일 탐색기에서 파일을 선택한 다음 Ctrl+Alt+P를 누르면 목록에 추가하고 창을 표시합니다. 자동으로 인쇄하지 않습니다.
이번에 추가된 개수, 전체 개수, 중복 개수를 표시합니다.
단축키를 누를 때마다 기존 목록에 누적합니다.
같은 파일명(다른 폴더 포함)은 팝업에서 추가를 누른 경우에만 중복 추가합니다.
목록을 확인하고 인쇄 버튼을 누르면 출력합니다.
창에 파일을 직접 끌어놓아도 개수를 표시합니다.
여러 파일 선택 지원. 프로그램을 완전히 닫으면 단축키도 꺼집니다.
압축파일 내부/가상폴더/바탕화면의 선택은 지원하지 않습니다. 압축을 푼 일반 폴더에서 사용하세요.
기존 버전 실행 창을 닫고 Install.cmd를 다시 실행하면 업데이트됩니다.

간편 인쇄 — Windows 10/11 64비트

1. 압축을 모두 풉니다.
2. Install.cmd를 더블클릭합니다. 최초 설치에 인터넷이 필요합니다.
3. 바탕화면 Quick Print를 실행합니다.
4. 프린터 선택 → 문서 파일 드래그 → 인쇄 버튼.

관리자 권한 없이 사용자 계정에 설치합니다. 최초 실행에는 수백 MB 다운로드가 발생할 수 있습니다.
PDF는 별도 뷰어 불필요. 한글은 한컴 한글 데스크톱, 엑셀은 Microsoft Excel 데스크톱이 필요합니다.
한글 보안 확인창이 뜨면 파일 열기를 허용하세요. 보안 기능을 자동으로 해제하지 않습니다.

기본 설정: 단면, 흑백, 전체 페이지, 모아찍기 없음, 1부.
원본 파일은 저장/수정하지 않습니다. 문서는 외부 서버로 업로드하지 않습니다.
PDF를 페이지별 흑백 이미지(300dpi)로 만들어 인쇄합니다.
페이지를 각각 별도 인쇄 작업으로 전송하므로 한 원본의 여러 페이지가 양면/모아찍기로 묶이지 않습니다.
단, 여러 작업을 자동 결합하는 복합기 서버/독자적인 드라이버 설정은 이 프로그램이 통제하지 못할 수 있습니다.
첫 사용 시 2페이지 문서로 출력 상태를 확인하세요. 전송 완료는 실제 종이 출력 완료를 뜻하지 않습니다.
용지는 프린터 설정을 사용하며 페이지 방향을 맞추고 인쇄 가능 영역 안에 비율 유지하여 축소/확대합니다.
엑셀은 숨겨지지 않은 모든 시트를 내보내고 저장된 인쇄영역 제한은 무시합니다.
기존 엑셀의 배율/페이지 구분/반복 제목 설정은 유지됩니다. 숨긴 시트는 인쇄하지 않습니다.
매크로 실행과 외부 링크 갱신은 차단합니다. 암호 PDF는 지원하지 않습니다.

중지: 현재 변환 또는 페이지 처리가 끝난 뒤 추가 전송을 멈춥니다.
이미 프린터에 보낸 페이지는 Windows 프린터 대기열에서 취소해야 합니다.
오류가 발생하면 후속 파일 전송을 멈춥니다. 이미 전송된 페이지는 되돌릴 수 없습니다.
목록이 남아 있으므로 재인쇄 전 완료 파일/페이지를 확인하세요.

설치 위치: %LOCALAPPDATA%\EunQuickPrint
삭제: 해당 폴더와 바탕화면 바로가기를 삭제하세요.

검증: Python 구문 검사 완료. 제작 환경이 Linux이므로 Windows COM, 드라이버, 실물 출력은 미검증입니다.
라이선스: Python, PySide6/Qt, PyMuPDF, Pillow, pywin32 등 각 배포물의 라이선스를 따릅니다.
PyMuPDF는 AGPL 또는 상용 라이선스이며 배포/변형 시 해당 조건을 확인하세요.
