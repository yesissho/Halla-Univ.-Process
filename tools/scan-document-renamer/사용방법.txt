스캔 문서 이름 정리 v1.9

프로그램 종료 → 새 폴더에 압축 모두 풀기 → Install.cmd 실행.
창 제목에 v1.9이 표시되어야 새 버전입니다.

파일 불러오기: SCAN_으로 시작하는 지원 문서만 표시, 기본 모두 체크.
파일명 확인: 체크한 문서에서 제목 자동 추출.
변경할 제목 칸을 더블클릭하면 텍스트를 직접 입력/수정할 수 있습니다.
수정 후 파일명 확인을 다시 누를 필요 없이 변경 버튼을 누르세요.
자동 인식 없이 직접 제목을 입력해서 변경하는 것도 가능합니다.
변경 버튼은 현재 표에 입력된 제목을 사용합니다. 확장자는 자동 유지.
체크한 파일만 변경하며, 제목이 비어 있으면 변경을 시작하지 않습니다.
변경하시겠습니까? 팝업에서 취소하면 변경되지 않습니다.
변경 중단을 누르면 아직 처리하지 않은 파일부터 중단합니다.
이미 변경된 이름은 유지합니다. 같은 이름은 (2), (3) 번호를 붙입니다.
파일명 금지문자는 공백으로 정리합니다.
상태 왼쪽 생성일자는 Windows 파일 생성 시각을 초까지 표시합니다.

검증: 편집 진입과 현재 입력값 전달, 취소/중단 코드 및 배포 구조 검사.
현재 환경에서 Windows GUI/OCR 실제 실행 검증은 하지 못했습니다.

설치 시 별도로 전달받은 영문·숫자 16자리 키를 입력하세요. 대소문자 구분.
키가 틀리거나 취소/닫기를 누르면 설치를 진행하지 않습니다.
이전 설치는 그대로 유지됩니다. 키 자체는 파일에 포함하지 않습니다.
