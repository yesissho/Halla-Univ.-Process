# 스캔 문서 이름 정리 v1.9

**삼성 스캐너의 `SCAN_`으로 시작하는 파일명 형식에서, 첫 페이지에 ‘제목’이라고 명시된 항목이 있는 문서에 한해 제목 자동 추출을 통한 파일명 변경을 지원합니다.**

학교명이나 AID 포함 여부에 따른 제한은 없습니다. ‘제목’ 항목이 없거나 인식되지 않으면 자동 추출할 수 없으며, ‘변경할 제목’을 더블클릭해 직접 입력할 수 있습니다.

## 설치

1. [Scan-Document-Renamer.zip](./Scan-Document-Renamer.zip)을 내려받아 압축을 모두 풉니다.
2. `Install.cmd` 실행 후 배포자에게 받은 **영문·숫자 혼합 16자리 설치 키**를 입력합니다. 대소문자를 구분하며, 키가 틀리거나 취소하면 설치하지 않습니다. 기존 버전은 종료 후 설치합니다.
3. 바탕화면 바로가기로 실행하고 필요하면 작업표시줄에 고정합니다.

Windows 10/11 및 한국어 Windows OCR이 필요합니다. 기본 폴더는 `C:\Users\user\Documents\Scan`입니다.

## 사용

1. **파일 불러오기**: `SCAN_` 접두의 PDF/JPG/JPEG/PNG/TIF/TIFF/BMP만 표시하며 기본 모두 체크됩니다.
2. **파일명 확인**: 체크한 문서의 첫 페이지에서 제목을 추출합니다.
3. **변경할 제목 더블클릭**: 원하는 제목을 직접 입력하거나 수정합니다. 수정 후 재확인은 필요 없습니다.
4. **변경**: 현재 입력한 제목으로 변경합니다. 확인 팝업에서 취소하면 변경하지 않습니다.
5. **변경 중단**: 다음 파일부터 중단합니다. 이미 변경된 파일명은 유지됩니다.

- 생성일자는 Windows 파일 생성 시각을 날짜·시·분·초로 표시합니다.
- 제목이 비어 있으면 변경을 시작하지 않습니다.
- 확장자와 문서 내용을 유지합니다. 같은 이름이 있으면 `(2)`, `(3)`을 붙이며 덮어쓰지 않습니다.
- Windows 파일명 금지문자는 공백으로 정리합니다.
- OCR은 PC 내부에서 처리합니다. 인쇄 품질과 도장·필기 겹침에 따라 인식 오류가 있을 수 있으므로 변경 전 제목을 확인하세요.

## 검증 상태

배포 구조와 편집·변경·확인·중단 코드 흐름을 검사했습니다. Windows GUI/OCR 실제 실행 및 인식 정확도는 제작 환경에서 검증하지 못했습니다.

## 설치 키 제한 범위

설치 스크립트는 키의 원문 대신 salt와 SHA-256 검증값만 포함합니다. 키는 배포자에게 별도로 전달받습니다. 이 기능은 일반 설치 경로를 제한하며, 공개 소스 수정이나 직접 실행까지 차단하는 라이선스 인증은 아닙니다. 이전 버전에는 소급 적용되지 않습니다.
