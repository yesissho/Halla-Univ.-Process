상태 및 아이콘 기준

진행 상태(문서)

✓ 완료모든 절차 완료
⟳ 처리 필요상신·문서번호 입력 등 내 처리 단계
◷ 대기상신 후 결재완료일 대기
Ⅱ 보류입력 여부와 관계없이 보류 처리

주요 절차 체크 항목 (문서 공통)

  • 결재 : 상신(올림) / 완료(결재됨)
  • 후결 : 대상자 · 상신(올림) · 결재완료일
  • 경리제출(지급문서) : 카드 / 현금 각각 제출일
  • 문서번호 : 번호 및 생성일자 입력
  • 완료 : 비고 입력 후 완료 처리
