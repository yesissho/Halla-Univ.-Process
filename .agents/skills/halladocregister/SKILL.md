# 제주한라대학교 기록물등록대장 입력

사용자가 요청한 기록물 정보를 제주한라대학교 SPOC 기록물등록대장에 입력한다. 기본 범위는 입력 행 작성까지이며 저장하거나 등록을 확정하지 않는다.

## 로그인과 보안

- `https://spoc.chu.ac.kr`에서 시작한다. 이미 로그인된 세션이면 그대로 진행한다. 인증 페이지로 이동하면 사용자가 직접 로그인할 때까지 기다린다.
- 비밀번호, 인증번호, 복구정보를 채팅이나 스킬 파일에 저장하거나 재사용하지 않는다. 로그인 정보 입력을 대신하지 않는다.
- 로그인 후 포털에서 인증된 사용자와 `기록물등록대장` 화면이 확인될 때만 계속한다. 다른 계정이거나 접근 오류가 나면 멈춘다.

## 입력 절차

1. **기록물등록대장**을 열고 현재 연도와 업무 부서를 확인한다. 사용자가 지정한 부서가 있으면 그 부서만 사용한다. 임의로 다른 부서를 선택하지 않는다.
2. 생산번호는 같은 연도·부서의 가장 최근 번호를 확인해 다음 번호를 사용한다. 사용자가 현재 마지막 번호를 알려주면 목록에서 확인 가능한지 대조한다. 목록이 불완전하거나 현재 번호와 충돌하면 추측하지 말고 멈춰 확인한다.
3. **추가**를 눌러 새 입력 행을 만든다.
4. 사용자 지시대로 다음 필드만 입력한다.
   - 생산번호: 직전 번호 다음 번호
   - 등록구분: 사용자가 지정한 값. 별도 지시가 없고 현재 작업이 내부결재 입력이면 `내부결재`
   - 생산일자: 오늘 날짜(한국 시간, `YYYY-MM-DD`)
   - 제목: 사용자가 지정한 제목. 제목이 없으면 입력 전에 확인한다.
5. 각 값이 입력 행에 반영되었는지 화면에서 확인한다. 별도의 `구분` 같은 추가 필드는 사용자가 지정하지 않았으면 추정해서 입력하지 않는다.
6. 입력 후 기록물등록대장 화면에 그대로 둔다. **저장, 등록, 제출 버튼을 누르지 않는다.** 완료 메시지에는 입력한 값과 저장 전 상태임을 알린다.

## 중단 조건

- 인증이 필요하면 사용자가 로그인할 때까지 기다린다.
- 다음 생산번호를 확정할 수 없거나 중복 번호가 보이면 추가 입력을 진행하지 않는다.
- 자동 저장으로 값이 확정될 가능성이 보이면 추가 입력 전에 멈추고 사용자에게 확인한다.
- 사용자가 지정한 필드만 작성하며 첨부, 결재권자, 수신자 등 다른 값은 건드리지 않는다.
- 실제 화면 요소나 문구가 안내와 다르면 버튼이나 필드를 추측해서 누르지 말고 현재 화면에서 확인 가능한 정보를 바탕으로 멈춘다.
