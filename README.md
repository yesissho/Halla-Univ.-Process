# 제주한라대학교 산학협력단 업무·결재·공문 통합관리 시스템

산학협력단의 키워드별 업무 문서(계획·시행·지급)와 공문(수신·발신)의 등록, 결재, 후결, 문서번호 관리 및 완료 처리를 한곳에서 관리하기 위한 요구사항 문서입니다.

## 핵심 원칙

- 일반 업무는 키워드를 기준으로 계획·시행·지급 문서를 연결합니다. 각 종류마다 기본 문서 1개를 제공하고, 필요한 만큼 추가할 수 있습니다.
- 추가 문서는 계획과 지급 선택이 가능합니다. 각 문서는 독립적인 결재 및 진행 상태를 가집니다.
- 결재 경로는 문서마다 선택하며, 후결이 발생하면 대상자를 자유 입력하고 전원 후결 완료 전에는 완료할 수 없습니다.
- 일반 업무 문서 완료에는 결재 완료, 필요한 경리 제출 및 문서번호·취득일 등록이 필요합니다.
- 공문은 업무 키워드와 분리하여 수신·발신으로 독립 등록합니다. 결재, 후결(발생 시), 공문번호와 취득일이 모두 갖춰져야 완료할 수 있습니다.
- 대시보드는 목차형으로 업무·공문을 탐색하고 상태별 색상으로 진행 상황을 보여줍니다. 선택 항목은 초록색, 필수 항목은 기본색으로 표시합니다.

## 범위 메모

이 문서는 대화에서 확인된 최종 요구사항을 정리한 기획 산출물입니다. 실제 결재 연동, 사용자 권한, 보존 기간, 첨부파일 정책 등 대화에서 확정되지 않은 세부 정책은 구현 전 별도 합의가 필요합니다.
