# 제주한라대학교 AID사업단 업무 진행 관리 도구

현재 배포된 최종 대시보드의 전체 소스입니다. 로그인 없이 주소를 열면 바로 대시보드로 접속합니다.

- 운영 주소: https://halla-aid-work-1110.sweetmyrtle1.chatgpt.site/
- 최종 배포: Sites 버전 27 (2026-11-10)
- 배포 원본 커밋: `c72c9c2ebfcbe3efee8e61c2d222ad31d853f601`

## 소스와 실행 파일

| 경로 | 역할 |
| --- | --- |
| `src/index.html` | 대시보드 HTML 원본 |
| `src/app.js` | 업무·문서 등록, 결재·후결, 경리제출, 상태 집계, 폴더 생성, 백업·복원 전체 로직 |
| `src/style.css` | PC·모바일 레이아웃 및 전체 스타일 |
| `src/campus.svg` | 화면에서 사용하는 이미지 |
| `scripts/build-static.mjs` | 원본을 배포 파일로 변환하고 파일명 해시 생성 |
| `dist/` | 현재 운영 사이트와 바이트 단위로 같은 배포 파일 전체 |
| `.openai/hosting.json` | 기존 Sites 프로젝트 ID와 배포 디렉토리 |
| `package.json` | 빌드·문법 확인 명령 |

별도 프레임워크·패키지 설치가 필요 없는 정적 HTML/CSS/JavaScript 사이트입니다. 서체는 Google Fonts의 Noto Sans KR을 요청하며, 접속이 안 되면 기본 sans-serif 서체를 사용합니다.

## 수정과 빌드

Node.js 환경에서 원본 파일을 수정한 뒤 실행합니다.

```sh
npm run check
npm run build
```

배포 대상은 `dist/`입니다. `src/index.html`의 `{{APP_FILE}}`, `{{STYLE_FILE}}`은 빌드 시 실제 해시 파일명으로 바뀝니다. `dist/app.js`도 배포에 포함된 동일 로직의 사본입니다.

로컬 확인은 저장소 루트에서 `python -m http.server 8000 --directory dist`를 실행하고 `http://localhost:8000`으로 접속합니다. GitHub 업로드와 기존 운영 사이트 배포는 별도 작업입니다.

## 최종 동작

- 로그인·사번 표시·계정 관리 기능은 제거했습니다.
- 결재문서 등록에서 업무 키워드와 계획·시행·지급 문서를 필요한 만큼 추가합니다.
- 등록·수정 창 하단은 취소 → 폴더생성 → 등록/저장 순서입니다.
- 폴더생성은 확인창에서 확인한 뒤 선택한 저장 디렉토리 아래 업무 키워드 폴더와 문서별 폴더를 만듭니다.
- 저장 디렉토리는 설정에서 선택합니다. 최초 폴더 선택창의 시작 위치는 바탕화면입니다. 실제 폴더 선택과 권한 허용이 필요합니다.
- 로컬 폴더 생성은 해당 API를 지원하는 PC 브라우저에서 동작합니다.
- 완료된 문서를 열면 완료해지 버튼이 표시됩니다. 완료해지는 결재·후결·문서번호·비고를 유지하면서 완료 상태만 해제합니다.
- 완료 조건이 부족하면 누락 사유와 “그래도 완료처리하시겠습니까?” 팝업을 표시합니다. 취소는 상태를 유지하고, 네는 미입력 항목이 있어도 완료로 저장합니다. 백업·복원 후에도 이 상태를 유지합니다.
- S02·S04 같은 화면 번호는 제거했습니다.
- 오류 안내는 열린 문서 창 상단에 표시합니다.

## 데이터 저장

업무 데이터는 사용 중인 브라우저의 localStorage에 저장합니다. 기존 `halla-aid-v2` 데이터와 이전 로그인 버전의 관리자 데이터 `halla-aid-v2:26733`을 이어서 읽습니다. 계정별 데이터를 사용한 적이 있으면 변경 내용을 두 키에 함께 저장합니다. 폴더 선택 정보는 IndexedDB에 저장합니다. 소스 저장소에는 사용자 업무 데이터·비밀번호·계정 DB를 포함하지 않습니다.

브라우저나 PC를 변경할 때는 사이트의 백업·복원을 사용하세요.
