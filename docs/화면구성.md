# 화면 구성 및 UI 시안

## 정보 구조

```text
업무·결재·공문 통합관리
├─ 대시보드
├─ 업무 관리
│  └─ 키워드 목록
│     └─ 키워드 상세
│        ├─ 계획 문서 (기본 1 + 추가)
│        ├─ 시행 문서 (기본 1)
│        └─ 지급 문서 (기본 1 + 추가)
├─ 공문 관리
│  ├─ 공문 수신
│  └─ 공문 발신
└─ 통합 검색
```

## 목차형 대시보드 와이어프레임

```text
┌────────────────────────────────────────────────────────────────┐
│ 제주한라대학교 산학협력단                         검색  사용자 │
├──────────────┬─────────────────────────────────────────────────┤
│ 목차         │ 대시보드                         [+ 업무 등록] │
│ ▾ 업무 관리  │ [전체 24] [진행중 9] [결재대기 4] [완료 11]     │
│   키워드 A   │                                                 │
│   키워드 B   │ 키워드 / 문서             진행 상태    담당자 │
│ ▾ 공문 관리  │ 산학과제 A                ● 진행 중    김○○ │
│   수신  3    │   계획 기본               ● 완료       ...    │
│   발신  2    │   시행 기본               ● 경리대기   ...    │
│ ▸ 검색       │   지급 기본               ● 결재대기   ...    │
│              │   [+ 계획 추가] [+ 지급 추가]                  │
└──────────────┴─────────────────────────────────────────────────┘
```

`● 완료`는 초록, `진행 중`은 파랑, `대기`는 주황, `반려/지연`은 빨강, `미시작`은 회색으로 표현한다. 색상만으로 정보를 전달하지 않고 상태명을 함께 표기한다. 문서 행을 누르면 상세 화면으로 이동한다.

## 업무 문서 상세

```text
┌───────────────────────────────────────────────────────────────┐
│ 업무 키워드: 산학과제 A  / 계획 기본             [저장]       │
├───────────────────────────────────────────────────────────────┤
│ 제목 [________________]  담당자 [________]                   │
│ 결재 경로 ( ) 단장 전결 ( ) 단장→산학 및 총장               │
│            ( ) 단장→사무처→산학 및 총장                      │
│ 결재 진행 [단장 완료] → [사무처 대기] → [산학·총장 대기]    │
│ 후결 [미발생/발생]  대상자 [+ 이름 입력]  완료 1/2           │
│ 문서번호 [____________] 취득일 [YYYY-MM-DD]                  │
│ 경리 제출 [선택/미선택] (시행 선택, 지급 필수)               │
│ 지급 수단 ( ) 카드 ( ) 현금 (지급 문서)                      │
│ 완료 점검  ✓ 결재  ✓ 후결  ! 문서번호  ! 취득일              │
│ [완료 처리] 비활성: 필수 정보 입력 후 활성화                  │
└───────────────────────────────────────────────────────────────┘
```

실제 문서 유형에 적용되지 않는 입력은 숨긴다. 예: 계획의 경리·지급 항목, 공문의 업무 키워드·경리 항목.

## 공문 등록·상세

- 목록 상단에 `수신 | 발신` 탭과 상태 필터를 제공한다.
- 독립 등록 폼: 방향, 제목, 발신처/수신처, 문서 날짜, 담당자, 첨부, 결재 경로.
- 상세 화면: 결재 진행, 후결 대상과 완료 수, 공문번호, 취득일, 완료 점검을 한 화면에 배치한다.
- 공문번호 또는 취득일이 비어 있거나 결재·후결이 남아 있으면 완료 버튼을 비활성화하고 부족한 항목을 표시한다.

## 상태·표식 규칙

| 의미 | 표현 |
|---|---|
| 완료 | 초록 배지 + `완료` |
| 진행 | 파랑 배지 + `진행 중` |
| 대기 | 주황 배지 + 구체적인 대기 사유 |
| 반려 또는 지연 | 빨강 배지 + 사유 |
| 미시작 | 회색 배지 + `미시작` |
| 선택 항목 | 초록 강조 및 `선택` 라벨 |
| 필수 항목 | 기본 텍스트 색 및 `필수` 라벨 |

선택/필수 표식은 필드의 입력 정책, 상태 배지는 현재 진행 상태를 뜻한다. 화면에서 이 둘의 색상 의미가 섞이지 않도록 텍스트와 아이콘을 병행한다.
