# 상세 기능명세

## 1. 업무 등록과 키워드

- 업무는 키워드 단위로 생성하고 제목, 담당자, 설명, 관련 파일 및 기본 정보를 기록한다.
- 키워드 아래 계획·시행·지급 문서의 기본 항목을 종류별 1개씩 자동 제공한다.
- 계획·시행·지급은 각기 독립된 문서 객체와 상태를 가진다.
- 계획과 지급 문서는 추가 생성할 수 있으며 생성 개수에 제한을 두지 않는다. 추가 계획과 추가 지급은 각각 선택 생성한다.
- 기본 문서의 삭제·비활성화 정책은 확정되지 않았으므로 별도 정책으로 정한다.

## 2. 결재

문서별 결재 경로를 다음 중 하나로 지정한다.

1. 단장 전결
2. 단장 → 산학 및 총장
3. 단장 → 사무처 → 산학 및 총장

`산학 및 총장`은 두 결재 주체 모두 완료되어야 다음 단계로 진행되는 병렬 단계로 해석한다. 결재자, 의견, 요청·처리 시각, 반려 사유를 기록한다. 반려 후 재상신 정책은 운영 정책으로 확정한다.

## 3. 후결

- 후결이 발생하는 경우 대상자 이름을 자유 입력해 등록한다.
- 등록된 모든 후결 대상자가 완료 처리되어야 후결 완료로 본다.
- 결재 승인만으로 후결을 대체하지 않으며, 후결 완료는 문서 완료 게이트에서 별도로 확인한다.
- 후결 대상자 추가·수정 이력과 완료 시각을 남긴다.

## 4. 문서번호와 취득일

- 일반 업무 문서에는 문서번호와 취득일을 입력한다.
- 문서번호와 취득일은 문서별 필수 완료 정보다.
- 값은 결재가 진행되는 동안 입력할 수 있으나, 완료 처리는 모든 게이트를 통과한 뒤 가능하다.

## 5. 경리 제출 및 지급 수단

- 시행 문서는 경리 제출 여부를 선택할 수 있다. 선택하지 않아도 완료 가능하다.
- 시행에서 경리 제출을 선택하면 경리 제출 완료 상태를 완료 게이트에 포함한다.
- 지급 문서는 경리 제출이 필수다.
- 지급 수단은 카드 또는 현금 중 하나를 기록한다.
- 지급 문서의 경리 제출 완료 전에는 완료할 수 없다.
- 경리 제출 대상 정보(수신자, 제출 일시, 메모)는 기록한다.

## 6. 공문 수신·발신

- 공문은 업무 키워드에 연결하지 않고 독립 등록한다.
- 한 목록에서 수신/발신을 구분하고 방향, 제목, 발신처 또는 수신처, 날짜, 담당자, 첨부를 기록한다.
- 공문별 결재 경로를 선택한다. 대화에서 표현한 `단장 전결 / 일반 결재 / 사무처 경유`는 일반 결재를 두 경로(단장→산학 및 총장, 단장→사무처→산학 및 총장) 중 선택하는 것으로 구체화한다.
- 후결이 발생하면 일반 업무와 동일하게 대상자를 자유 입력하고 전원 완료를 요구한다.
- 공문번호와 공문번호 취득일은 수신·발신 모두 필수다.
- 결재 완료, 후결 완료(발생 시), 공문번호 및 취득일 입력을 모두 만족해야 담당자가 완료 처리할 수 있다.
- 경리 제출, 업무 키워드, 계획·시행·지급 단계는 공문에 적용하지 않는다.

## 7. 완료 게이트

| 문서 유형 | 필수 완료 조건 |
|---|---|
| 계획 | 결재 완료 + 후결 대상 전원 완료(발생 시) + 문서번호 + 취득일 |
| 시행 | 계획 조건 + 경리 제출을 선택한 경우 제출 완료 |
| 지급 | 계획 조건 + 경리 제출 완료 + 지급 수단(카드/현금) |
| 공문 수신·발신 | 결재 완료 + 후결 대상 전원 완료(발생 시) + 공문번호 + 취득일 |

완료 버튼은 조건을 시스템에서 계산해 충족 시에만 활성화한다. 미충족 항목과 이동 링크를 화면에 표시한다. 완료 시각과 처리자를 기록한다.

## 8. 대시보드·검색

- 목차형 내비게이션으로 업무 키워드, 공문 수신, 공문 발신에 접근한다.
- 키워드 행을 펼쳐 관련 계획·시행·지급 문서와 추가 문서를 확인한다.
- 전체/진행 중/결재 대기/후결 대기/경리 제출 대기/완료 등 상태 필터를 제공한다.
- 키워드, 제목, 담당자, 문서번호, 공문번호로 검색한다.
- 상태 색상은 완료=초록, 진행 중=파랑, 대기=주황, 반려/지연=빨강, 미시작=회색을 기본으로 한다.
- 항목 종류 표시에서 선택 사항은 초록 강조, 필수 사항은 기본 색으로 표시한다. 상태 배지와 선택/필수 표시가 서로 혼동되지 않도록 텍스트 라벨과 아이콘을 함께 쓴다.
